# Tic-Tac-Toe App

A real-time Tic-Tac-Toe game built using **React.js**, **Node.js**, **Socket.IO**, and **Tailwind CSS**. It provides both online and offline gameplay with additional features to track wins and losses.

---

## Features

- **Play Offline**: Enjoy the classic game against a friend on the same device.  
- **Play Online**: Connect and play with friends in real-time.  
- **Rematch Request**: Easily request a rematch after finishing a game.  
- **Track Wins and Losses**: Keep a record of your gameplay stats.  

---

## Technologies Used

- **React.js**: A JavaScript library for building the user interface.  
- **Node.js**: A JavaScript runtime environment used to build the backend server.  
- **Socket.IO**: A library for real-time, bidirectional communication between clients and server.  
- **Tailwind CSS**: A utility-first CSS framework for styling the application.
